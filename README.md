# kinetic-gain-docs-hub

Quickstart hub for the [Kinetic Gain Protocol Suite](https://suite.kineticgain.com). Per-role guides ("I'm a CISO," "I'm a school district," "I'm a healthcare vendor"), the canonical `/.well-known/` path map for every spec, and a 30-second quickstart.

Live at **[docs.kineticgain.com](https://docs.kineticgain.com)**.

Hand-written HTML + CSS, no build step, FTPS-deployed to Hostinger on push to `main`.
