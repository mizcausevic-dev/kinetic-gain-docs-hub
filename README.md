# kinetic-gain-docs-hub

Quickstart hub for the [Kinetic Gain Protocol Suite](https://suite.kineticgain.com), Atlas, and the wider Kinetic Gain operator stack. Per-role guides ("I'm a CISO," "I'm a school district," "I'm a healthcare vendor"), the hosting/path map for all 12 specs, including artifact-bound cards, and a 30-second quickstart aligned to the published 12-spec Suite and its wider operator ecosystem, including newer cloud-admin, biotech, diagnostics, nonprofit, and polyglot surfaces.

Live at **[docs.kineticgain.com](https://docs.kineticgain.com)**.

Hand-written HTML + CSS, no build step, FTPS-deployed to Hostinger on push to `main`.
